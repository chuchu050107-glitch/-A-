# เว็บไซต์สอน Python — วิชา 618240 โครงสร้างข้อมูลและอัลกอริทึม

เว็บไซต์เรียน Python แบบ static เรียบเรียงจากเอกสารบรรยาย 7 บทในโฟลเดอร์แม่
ทุกโค้ดตัวอย่างแก้ไขและกดรันได้จริงในเบราว์เซอร์ ไม่ต้องติดตั้ง Python

## วิธีเปิด

**วิธีที่ 1 — ดับเบิลคลิก** ที่ไฟล์ `index.html` ได้เลย

**วิธีที่ 2 — เปิดผ่าน local server** (ถ้าวิธีแรกมีปัญหา)

```bash
python -m http.server 8765 --directory "python-course"
```

แล้วเปิด http://localhost:8765 ในเบราว์เซอร์

## สิ่งที่ต้องรู้

- **ครั้งแรกที่กดรัน ต้องต่ออินเทอร์เน็ต** เพื่อดาวน์โหลดตัว Python
  ([Pyodide](https://pyodide.org) ~10 MB) หลังจากนั้นเบราว์เซอร์จะ cache ไว้
- โค้ดที่ใช้ `input()` ให้พิมพ์ค่าลงช่อง **ข้อมูลนำเข้า (stdin)** บรรทัดละ 1 ค่า ก่อนกดรัน
- โค้ดที่แก้จะถูกจำไว้ใน localStorage ของเบราว์เซอร์ กดปุ่ม **รีเซ็ตโค้ด** เพื่อกลับเป็นตัวอย่างเดิม
- Python ทำงานบนหน้าเว็บโดยตรง ถ้าเขียนลูปไม่รู้จบหน้าเว็บจะค้าง ต้องรีเฟรช

## สอบมิดเทอม

หน้า **📝 สอบมิดเทอม** ในเมนูซ้าย ครอบคลุมเนื้อหาบทที่ 1-7 แยกเป็น 2 หน้าย่อย
สลับได้จากแท็บด้านบนหรือจากลิงก์ย่อยในเมนูซ้าย (คำตอบที่เลือกไว้ไม่หายเมื่อสลับไป-กลับ)

- **ส่วนที่ 1 ปรนัย บทละ 20 ข้อ รวม 140 ข้อ** (`#/exam/choice/1` ถึง `/7`) —
  แยกหน้าตามบท เลือกบทได้จากแถบด้านบน คละความยากง่าย/กลาง/ยาก
  แต่ละบทกดปุ่ม *ตรวจคำตอบ* แยกกัน แล้วได้คะแนนพร้อมคำอธิบายรายข้อ
  บทที่ตรวจแล้วจะมีจุดสีเขียวกำกับบนแถบเลือกบท
- **ส่วนที่ 2 อัตนัย 7 ข้อ** (`#/exam/written`)
  1. เขียนโปรแกรม — คลาส `Stack` และการประยุกต์กลับลำดับตัวอักษร (บทที่ 6)
  2. อ่านโค้ดแล้วตอบผลการรัน — Insertion Sort, merge และ recursion (บทที่ 4 และ 5)
  3. เขียนโปรแกรม — ดัดแปลง Merge Sort ให้เรียง record ตามคะแนนจากมากไปน้อย (บทที่ 5)
  4. เขียนโปรแกรม — Selection Sort เรียง record ตามคอลัมน์ที่ระบุ (บทที่ 4) *เพิ่มเติมเพื่อออก*
  5. อ่านโค้ดแล้วตอบผลการรัน — Stack เต็ม/ว่าง และลำดับ FILO (บทที่ 6) *เพิ่มเติมเพื่อออก*
  6. เขียนโปรแกรม — `LinkedList` ที่มี insertAtTail/insertAtHead/removeAtHead/search (บทที่ 7) *เพิ่มเติมเพื่อออก*
  7. เขียนโปรแกรม — ฟังก์ชันเรียกตัวเองนับข้อมูล และคิว FIFO ด้วย `deque` (บทที่ 5 และ 7) *เพิ่มเติมเพื่อออก*

ข้อที่ติดป้าย **เพิ่มเติมเพื่อออก** คือโจทย์ที่เพิ่มเข้ามาจากเนื้อหาบทที่ 4-7

เฉลยทุกข้ออิงโค้ดจากสไลด์ และกดรันดูผลลัพธ์ได้ในหน้าเว็บ

## โครงสร้างไฟล์

```
python-course/
├── index.html          โครงหน้าเว็บ
└── assets/
    ├── styles.css      สไตล์ทั้งหมด (ธีมสว่าง/มืด, responsive)
    ├── lessons.js      เนื้อหาบทเรียนทั้ง 7 บท
    ├── exam.js         ข้อสอบมิดเทอม (ปรนัย + อัตนัย + เฉลย)
    ├── runner.js       โหลดและสั่งรัน Python (Pyodide)
    └── app.js          router, ตัวแก้ไขโค้ด, การบันทึกลง localStorage
```

การเพิ่มบทหรือแก้เนื้อหา ทำที่ `assets/lessons.js` ส่วนข้อสอบแก้ที่ `assets/exam.js`
